One option (Size) generates the variant matrix; every variant row edits in place — SKU/barcode in the mono face, money right-aligned. Cost sits next to price so margin is visible while typing (cost never reaches the receipt). Stock column is single-location in Phase 1 and reads "Stock · Poblacion" so multi-location (Phase 4) is an added column, not a redesign. Description copy names where it appears — no dead fields. Editor screens collapse the sidebar to an icon rail: the work needs the width.
